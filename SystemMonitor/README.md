# SystemMonitor

System-Überwachungstool mit grafischer Oberfläche (Python/Tkinter).

## Funktionen

- **CPU-Auslastung** – Echtzeit-Anzeige der Prozessorauslastung
- **RAM-Auslastung** – Aktueller Arbeitsspeicherverbrauch
- **Datenträger-Auslastung** – Festplatten-/SSD-Belegung
- **Netzwerk** – Aktuelle Netzwerkaktivität (Upload/Download)

Alle Werte werden mit farbigen Fortschrittsbalken visualisiert.
